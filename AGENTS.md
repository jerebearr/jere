# Team Instructions

These instructions apply to the entire repository.

## Project layout

- Keep Roblox game work inside `Roblox/`.
- Keep pickleball paddle work inside `PickleballPaddle/`.
- Do not mix files from the two projects.

## Safe changes

- Do not delete or overwrite important files unless explicitly asked.
- Preserve older design revisions and working versions.
- Do not commit passwords, API keys, tokens, or private personal information.
- Explain any assumptions before making a change that could affect both projects.

## Git workflow

- Pull the latest `main` branch before starting work.
- Use a separate branch for each feature, experiment, or fix.
- Keep commits small and describe what changed.
- Do not force-push or rewrite `main`.
- Review changes before merging a pull request.

## Completion checklist

Before finishing a task:

- Check the changed files.
- Test or manually review the affected project when possible.
- Report what changed and what was not tested.
